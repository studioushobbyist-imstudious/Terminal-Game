# Ascii Font
transparent character
character : translates characters works by  U+... too:
mode: name
spacing: space between letters
size : determines spacing when turning it into a texture
glyph

name of the font itself is the file name
eg Terminal-Gothic.af

you can skip sizes and when making font texture, itll snap to the nearest available size (x and  y)
Ex. request size 3 for 'a' but font only has 5x7 and 7x9 for 'a'
pick closest one overall 5x7

give font mode a name
